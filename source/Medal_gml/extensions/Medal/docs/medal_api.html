medal_event_invoke

Tells Medal that something worth clipping just happened. A 200 means Medal accepted the event; the clip itself is processed asynchronously and appears in the player's library after the configured duration has elapsed.

This function operates asynchronously, which means that it does not immediately return the requested result. Instead, upon completion of the task, it will trigger the Callback.


Syntax:

medal_event_invoke(_body=undefined, _callback=undefined)
Argument Type Description
_body MedalEventInvokeRequest The body to be included in the http request.
_callback Function Callback with signature (status, data, request). status is the HTTP status code, or negative when the request never reached a server.


Returns:

N/A


Triggers:

Callback

Key Type Description
_status Real The HTTP status code, or a negative value if the request never reached a server (no connection). Check for a negative value before treating it as an HTTP code.
_data Any
_request MedalRequest
