MedalClipOptions

This struct is referenced by the following structs:

  • MedalEventInvokeRequest


Member Type Description
duration Real Length of the saved clip in seconds. Medal documents a typical range of 15 to 60.
captureDelayMs Real Milliseconds Medal waits after the request before snapshotting the replay buffer. Useful for catching a killcam or another post-action moment.

MedalEventInvokeRequest

This struct is referenced by the following functions:

  • medal_event_invoke


Member Type Description
eventId String The numeric ID assigned to this event, as a string (for example "1"). Medal uses it to let players toggle individual events on or off.
eventName String Display name used to label the clip card in Medal.
triggerActions Array of String The actions Medal should perform for this event. Use ["SaveClip"] to record and save a highlight.
clipOptions MedalClipOptions How Medal should capture the clip for this event.

MedalRequest

The in-flight HTTP request, handed to every callback as its third argument. Call retry() on it to send the same request again - useful from a response hook that has just refreshed a credential. get_callback() returns the callback it will invoke.

This struct is referenced by the following functions:

  • medal_event_invoke


Member Type Description
attempts Real How many times this request has been sent, including retries.
