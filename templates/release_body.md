## IMPORTANT

- This extension is to be used with GM 2022.9 and future releases.
- Works with **all platforms** (pure GML, no native code).
- Requires the **Medal desktop app** to be running on the player's machine.

## DESCRIPTION

Reports clip-worthy game events to Medal's local auto-clipping API, so Medal saves a highlight from
its replay buffer.

## FEATURES

- Fire a Medal clip event with a single function call
- Typed request structs with argument validation
- Asynchronous, callback-based HTTP handled for you
- REST client generated from a checked-in OpenAPI spec

## DOCUMENTATION

The full documentation of the API is included in the extension asset (included files).
